WHITE LION BOSS - Android project (Capacitor + AdMob)

APK BANAVVA (Android Studio vagar):
1. github.com par free account banavo > New repository (naam: lionrunner, Private ke Public).
2. Aa folder ni BADHI files (hidden .github folder sathe) repository ma upload karo
   (Add file > Upload files). node_modules folder nathi, tene upload na karo.
3. Repository > Actions tab > "Build APK" > Run workflow. 5-8 minute rahi jovo.
4. Run puru thay pachi niche "Artifacts" ma "WhiteLionBoss-apk" download karo (zip).
   Zip ni andar app-debug.apk che. Aa j users ne WhatsApp/Drive thi moklo.

PRIVACY POLICY URL (free):
1. docs/privacy.html ma YOUR_EMAIL_HERE ni jagya e potano email lakho.
2. Repository > Settings > Pages > Branch: main, Folder: /docs > Save.
3. URL: https://TAMARU-USERNAME.github.io/lionrunner/privacy.html
   (Aa URL AdMob / Play Store ma vaparso. Pages free mate repo Public rakhvi pade.)

ADS (pachi): AdMob ma app ane ad units banavya pachi,
 - www/index.html ma ADCFG ma real IDs ane TEST_MODE:false
 - android/app/src/main/AndroidManifest.xml ma APPLICATION_ID badlo
Aa fer-far mane kaho to hu kari dau.
